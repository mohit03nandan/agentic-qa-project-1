# Udemy Course Sequence — AI/Agentic Testing

Recommended order for the 4 courses found, with reasoning. General idea: **understand → build → test**.

---

## 1. Generative AI in Software Automation Testing
https://www.udemy.com/course/generative-ai-in-software-automation-testing/

The broadest, most beginner-friendly one. Good warm-up — a lot of this will already feel familiar from the tutoring sessions in [Agentic-QA-Revision-Notes.md](Agentic-QA-Revision-Notes.md), which builds confidence. Also adds a new angle not covered yet: using AI to help *write* tests, not just testing AI itself (test case/data generation, AI-assisted UI test automation).

## 2. AI with HuggingFace
https://www.udemy.com/course/ai-with-huggingface/

Goes one level deeper than the roadmap did — actual hands-on work with real open-source models (not just calling Ollama), fine-tuning, quantization, and how transformers really work under the hood. Good technical foundation before building bigger things.

## 3. Build AI Agent, ChatBot, RAG with LangChain + Local LLM
https://www.udemy.com/course/build-ai-agent-chatbot-rag-langchain-local-llm/

The roadmap's RAG app (`rag_app.py`) and agent (`shoe_store_agent.py`) were built completely from scratch on purpose, to see the mechanics with nothing hidden. This course teaches the same ideas using **LangChain**, the real industry-standard framework most jobs expect familiarity with. Good to see the "proper tool" version now that the underlying mechanics are already understood. Also touches evaluating agents/RAG with RAGAS toward the end.

## 4. AI Testing with DeepEval, RAGAS, Ollama
https://www.udemy.com/course/ai-testing-deepeval-ragas-ollama/

Save this for last — closest match to the actual goal (agentic AI tester). Covers almost exactly what was already done hands-on: DeepEval, RAGAS-style checks, Ollama, GEval, RAG testing, bias detection. By this point, this course reinforces and formalizes skills already built, rather than starting from zero — should click the fastest.

---

## Why this order
Courses 1–2 build foundation, course 3 builds real apps with a real framework, course 4 teaches how to test them properly — matching the actual target role.
